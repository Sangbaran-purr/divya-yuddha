# SCALE GRAMMAR AMENDMENT (owner ruling): effect scale maps to
# card type, creating a readable visual language. Amends v4/v5
# routing; all generation and audit laws unchanged.

## THE GRAMMAR
G1. HERO + UNIT plays: CARD-ANCHORED. Faction landings (C1) at
    card scale - a body arrived. Full edge law (all four sides
    fade to black).
G2. ASTRA casts: TWO-LAYER. Row stage plate (the invocation
    sweeps the row - B-class or C2 signature as the stage) PLUS
    a card-anchored strike on the actual target (targeting
    legibility law: the mechanical truth always reads at the
    target card). Row-plate edge law (left/right may burn to
    edge; top/bottom fade).
G3. MANTRA casts: PURE ROW WASH - chants are row/global by
    nature. Row-plate edge law.
G4. ARTIFACT plays: ROW RIPPLE on arrival + persistent
    card-anchored idle glow thereafter (no permanent row plates -
    visual weight law).
G5. Spectacle tier (hero moment) sits above this grammar
    unchanged; its beat elements adopt the type-correct scale
    per G1-G4 as they migrate.

## SEQUENCING (test-piece order, ruled)
Test 1: C1a Deva landing (card-anchored class proof - the most-
        fired effect in the game, hardest audit per F1).
Test 2: B1 fire sweep (row-plate class proof).
Both classes proven -> Wave 1 production across the grammar.
